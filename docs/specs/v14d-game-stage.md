# 游戏截图参考渲染迁移规格

## 目标与状态

将用户已认可的独立预览迁入共享 MMD 舞台，新增 `v14d-game` 渲染类型。当前为迁移规格，尚未实现或验收。不是游戏着色器或 Blender 数值等价证书。

## 用户行为与默认值

用户能够选择新类型、看到已认可外观、继续使用现有动作和相机、调整参数、保存和恢复默认，并切回旧类型。默认显示为本机 OCIO，曝光 -0.40，织纹对比 2，纵向细线 1，目标闭眼，微笑，虹膜参考光感 2，脸部阴影自动选择开启，手动遮罩初值 2，六灯开启。圆盘实验关闭。头部、模型和主光旋转初值 0。

纵向细线只增强缝线，不分成两种底色。自动遮罩由实际角度派生，不固定状态 2。微笑使用口角形变，不覆盖眼部笑形变。

## 实现决策与不变量

- 复用共享 MMD 模型、动作、口型、相机和释放生命周期；不嵌入预览页面、不复制播放循环。
- 绘制期表情覆盖必须异常安全恢复，不破坏动作及说话权重。提供跟随动作语义。
- 六灯位置和尺寸按模型实际缩放映射；保持原辐亮度，不把尺寸扩大后的固定功率误作相同照明。
- 角色显示变换与背景分开；切换模式完整释放新模式资源、恢复旧模式配置。
- 本机 OCIO 派生资源许可未确认，仅存 Git 忽略缓存，不进入发布包；通过白名单资源接口读取，拒绝路径穿越。资源缺失明确不可用，不静默替代显示算子。
- 模型专用材质映射不得应用到不支持模型。
- 类型通过前端、API 和数据库校验与保存；微调按用户、模型、新类型独立版本化保存，不借用 Reze 场景文档。

## 纵向实施顺序

1. 舞台接入：选择新类型后，真实模型使用固定截图默认外观；可播放动作、切回旧类型。阻塞：无。
2. 微调与保存：舞台调整上述参数、重载保持、恢复截图默认。阻塞：1。
3. 独立验收与集成：真实动作、口型、相机、模式往返、缺失资源和旧模式回归。阻塞：1、2。

## 验收证据

每步提供实际运行命令、退出码、变更列表和未覆盖项。验证选择、默认值、渲染就绪、参数可见变化、动作推进、口型不被永久覆盖、相机操作、切换释放、非法与缺失资产拒绝。API存根证据不得表述为真实后端联调。视觉由来源主会话核验，不以单元测试替代。不得沿用旧完整验收证书。
